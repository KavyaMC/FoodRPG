Installing Food RPG
  1. Clone or download the project.
  2. Install the required Python packages.
  3. Install and configure the Prism speech backend.
  4. Run the game using Python.
Creating a New Game

Start a new game, create your character, choose a business type, and begin building your food business.

Menu Navigation

Menu Navigation Controls

Down Arrow / K Move to the next option

Saving Your Progress

Food RPG supports multiple save slots. Select a save slot from the Save menu and confirm your choice.

Accessibility Features
  • Fully keyboard-driven gameplay
  • Audio-first interface
  • Speech feedback throughout the game
  • Context-sensitive help
  • Screen reader-friendly design
Troubleshooting

The game won't start: Verify Python, Pygame and the Prism speech backend are installed.

I can't hear speech: Check your audio output and speech backend.

Keyboard controls aren't responding: Make sure the game window has focus.
