Overview

Food RPG is a single-player, audio-first business simulation game built with accessibility at its core.

You begin with a small food business and gradually build your operation by managing resources, serving customers, and making strategic decisions. The game is designed so that all core gameplay can be experienced through keyboard input and speech feedback.

Core Experience

Food RPG focuses on a guided simulation loop where players:

  • Start a new game or load an existing save
  • Create a character and select a starting business type
  • Progress through structured gameplay stages
  • Make decisions using accessible menu navigation
  • Manage basic business operations within the game world
  • Save and continue progress across sessions
Accessibility Design

The game is designed for full keyboard-based interaction and audio feedback.

Key accessibility features include:

  • Simplified navigation flows for clarity and consistency
  • Keyboard-only navigation
  • Speech feedback for game events and menus
  • Context-sensitive help prompts
  • Structured, screen-reader-friendly interfaces
Save System

Food RPG supports multiple save slots.

Players can:

  • Create a new save
  • Load previous progress
  • Continue gameplay across sessions

Each save stores progression, settings, and game state.

Input System

All gameplay is designed around keyboard interaction.

Common controls include:

  • H for help and control guidance
  • Arrow keys / letter navigation for menu movement
  • Enter / Space to select actions
  • Escape / Backspace to return to previous screens
Gameplay Structure

The game follows a structured simulation loop:

  • Decision-based menus
  • Resource management
  • Progress tracking through in-game systems
  • Context-driven choices that affect gameplay flow
Technical Note

Food RPG is built using Python and Pygame with an audio-first design approach to ensure compatibility with assistive workflows.

Project Status

Food RPG is an actively developed single-player game. Core gameplay systems, accessibility features, and save functionality are currently implemented and evolving through iterative updates.

Frequently Asked Questions

What is Food RPG?

Food RPG is an accessible, audio-first business simulation game. Players start with a small food business and progress by managing resources, serving customers, and making business decisions through keyboard-driven gameplay.

Who is Food RPG designed for?

Food RPG is designed for everyone, with accessibility as a core focus. The game supports keyboard-only navigation and speech feedback, making it suitable for blind and visually impaired players.

Do I need a mouse to play?

No. The game is designed to be fully playable using only the keyboard.

Does the game support screen readers?

Yes. Food RPG is developed with accessibility in mind and is designed to work alongside speech and screen reader workflows.

What operating system does Food RPG support?

Food RPG currently runs on systems capable of running Python, Pygame, and the required speech backend.

What do I need to install before playing?

You will need Python 3.10 or later, Pygame, and the Prism speech backend. Installation instructions are available in the project documentation.

Can I save my progress?

Yes. Food RPG supports multiple save slots, allowing you to save your progress and continue later.

Is there a tutorial?

Yes. The game includes an introduction that explains the story, objectives, and basic controls. Context-sensitive help is also available throughout the game.

How do I learn the keyboard controls?

Press H during supported screens to hear the available controls and navigation guidance.

Is an internet connection required?

No. Food RPG can be played offline after it has been installed.

Is the game free to play?

Yes. Food RPG is currently available to download and play for personal use.

Where can I report bugs or accessibility issues?

You can contact the development team using the support email listed on the website or by opening an issue on the project's repository.

Can I contribute to the project?

Yes. Feedback, accessibility suggestions, bug reports, and code contributions are welcome. Please refer to the project's documentation for contribution guidelines.

How often is Food RPG updated?

Updates are released as development progresses. Major changes and announcements are published on the Announcements page.

Where can I find the latest documentation?

The Food RPG page contains project information, controls, accessibility details, and documentation about the current version of the game.
